A key, and where it may send from

A key is the password one application uses. It is restricted to the sender addresses you tick when creating it, so a leaked key can send as those and nothing else — it cannot read your mail bodies, touch another project's messages, or change any settings. Create one.

Why the AI already knows this API

emaild is wire-compatible with Resend, which assistants have been trained on. Telling it "this is a Resend-compatible API at {{ base_url }}" is usually enough on its own; the brief above just removes the guesswork about which fields exist.

The one thing it will get wrong

Resend reports delivered. emaild never does, because on this provider it cannot be proven — accepted_by_provider is terminal and means the provider took custody, not that anything arrived. An assistant that polls for delivered will wait forever. That is stated in the brief.
