What a result actually tells you

This goes through the same path your application will use — the same authorization, the same limits, the same queue.

queued emaild stored it. Nothing has been sent yet.
accepted_by_provider MXRoute took custody and answered 250. This is as far as any proof goes — it is not confirmation of delivery.
permanently_rejected It will not be retried. The message page names the reason, and Messages keeps the history.
nothing arrives Check spam first. Then open the message's original source and confirm SPF, DKIM and DMARC all pass — a domain can be ready here and still be treated as spam elsewhere.

Test messages count against the sender's 400-per-hour budget and appear in Messages like any other.
